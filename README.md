# Course Fetch

**一键整理、批量下载北大教学网「课堂实录」录像的浏览器脚本。**

**[⬇ 一键安装最新版](https://github.com/MiniYuanBot/course-fetch/releases/latest/download/course-fetch.user.js)**（需先完成下面的第一、二步）· [所有版本与更新说明](https://github.com/MiniYuanBot/course-fetch/releases)

打开课程的课堂实录页面，Course Fetch 会自动列出整门课的全部录像，按时间排好序并统一命名，如 `L01-2026-09-07-第7-8节.mp4`。勾选后点一下，就能把录像直接保存成可以播放的 MP4 文件。

## 为什么用 Course Fetch

- 🗂 **整门课一次列全**：自动翻页收集所有录像，去掉重复项，按上课时间从 L01 开始编号。
- 🏷 **文件名统一规范**：默认 `L序号-日期-第x-x节.mp4`，命名模板可以自定义，下载后不用再手动改名。
- 📦 **批量下载**：勾选多条录像，只选一次保存位置，默认同时下载 3 条。某条失败不影响其它条，可以单独取消某条或整批取消。
- 🎬 **直接得到 MP4**：边下载边转换成 MP4，**不重新编码，画质音质与原视频完全一致**；文件比原始格式还小约 5–10%，用系统自带播放器就能打开。
- 💾 **直接写入硬盘，不占内存**：几 GB 的录像也是边下边存，电脑不会因为下载而变卡。
- 📊 **进度清清楚楚**：显示百分比、已下载大小、速度和预计剩余时间；批量结束后列出每条结果，确认后恢复页面。
- 🔒 **安全，不越权**：只使用你当前登录的账号本来就能观看的录像，不破解、不绕过任何权限；不会保存你的账号信息或视频密钥。
- 🧩 **装上即用，自动更新**：点一下链接就能安装，发布新版本后 Tampermonkey 会自动更新，不需要安装其它软件。

> 课堂录像的版权归授课教师和学校所有。请仅用于个人学习，并遵守学校的相关规定，不要传播。

## 准备工作

| 项目 | 要求 |
| --- | --- |
| 浏览器 | 推荐电脑版 **Chrome** 或 **Edge**。Firefox 也能用，但只能单条下载，并且会占用较多内存（见[常见问题](#常见问题)） |
| 扩展 | Tampermonkey（油猴），下面会一步步安装 |
| 脚本 | 从 [Releases 页面](https://github.com/MiniYuanBot/course-fetch/releases/latest) 安装，见第三步 |
| 账号 | 能正常登录北大教学网，并且能在网页上播放要下载的录像 |
| 硬盘空间 | 每节课（约 2 小时）的录像约 0.6–1 GB |

## 第一步：安装 Tampermonkey

1. 用 Chrome 或 Edge 打开 Tampermonkey 官网：<https://www.tampermonkey.net/>。
2. 点击与你浏览器对应的下载按钮，进入扩展商店：
   - Chrome：Chrome 网上应用店
   - Edge：Microsoft Edge 加载项
3. 点击「添加至 Chrome」或「获取」，在弹出的确认框中点「添加扩展程序」。
4. 安装完成后，点击浏览器右上角的拼图图标 🧩，找到 Tampermonkey，点旁边的📌图钉，把它固定到工具栏上，方便之后使用。

## 第二步：允许 Tampermonkey 运行脚本

新版 Chrome 和 Edge 要求手动允许扩展运行用户脚本，**跳过这一步脚本不会生效**。

**Chrome：**

1. 在地址栏输入 `chrome://extensions` 并回车。
2. 找到 Tampermonkey，点击「详细信息」。
3. 打开 **「允许用户脚本」（Allow User Scripts）** 开关。
   - 如果找不到这个开关，说明你的 Chrome 版本较旧：改为打开页面右上角的 **「开发者模式」** 开关。

**Edge：**

1. 在地址栏输入 `edge://extensions` 并回车。
2. 打开左侧（或页面上方）的 **「开发人员模式」** 开关。
3. 找到 Tampermonkey，点击「详细信息」，如果有 **「允许用户脚本」** 开关，也一并打开。

## 第三步：安装 Course Fetch 脚本

1. 打开最新版本的 [Releases 页面](https://github.com/MiniYuanBot/course-fetch/releases/latest)。
2. 在页面下方的 **Assets** 中点击 **`course-fetch.user.js`**，也可以直接点这里：[安装最新版](https://github.com/MiniYuanBot/course-fetch/releases/latest/download/course-fetch.user.js)。
3. Tampermonkey 会自动打开安装页面，显示脚本名称 **Course Fetch** 和版本号，点击 **「安装」**。
4. 点击 Tampermonkey 图标 →「管理面板」，确认列表中有 **Course Fetch**，并且右侧开关是**开启**状态。

> **没有弹出安装页面、而是直接下载了文件？** 说明前两步还没完成，或者 Tampermonkey 没有启用。检查后重新点击安装链接即可。
> 也可以在 Tampermonkey 管理面板的「实用工具 → 从 URL 安装」中粘贴上面的安装链接。

## 第四步：打开课堂实录，确认脚本已运行

1. 登录 [北大教学网](https://course.pku.edu.cn)，进入一门有录像的课程，点击左侧菜单中的 **「课堂实录」**。
   - 建议从课堂实录的**第 1 页**进入，这样脚本能收集到全部分页。
2. 稍等片刻，页面**右下角**会出现一个小条：`Course Fetch · 32 条`（数字是录像条数）。脚本会自动扫描所有分页，扫描时显示「扫描中…」。
3. 点击这个小条，展开 Course Fetch 面板。

第一次下载时，Tampermonkey 可能会弹窗询问是否允许脚本访问 `pku.edu.cn` 下的某个域名（例如 `resourcese.pku.edu.cn`），请选择 **「总是允许」**。

## 第五步：检查录像列表

面板中各项的含义：

| 区域 | 说明 |
| --- | --- |
| **课程** | 自动识别的课程名。识别得不准可以直接修改，修改后会被记住 |
| **命名模板** | 文件名规则，默认 `L{index:02d}-{date}-第{periodStart}-{periodEnd}节.mp4`，修改后列表中的文件名会实时更新；点「重置」恢复默认 |
| **输出格式** | 默认 **MP4（推荐）**；也可以选 **TS（原始流）**。选择会被记住 |
| **录像列表** | 按上课时间排序，L01 是最早的一节课。每行有「打开」「复制名」「下载」三个按钮 |
| **提示** | 如果有解析失败、翻页失败、重复录像等情况，会在这里列出 |

## 第六步：选择下载目录（重要）

无论单条下载还是批量下载，第一次点击下载时浏览器都会弹出**「选择文件夹」**窗口，并询问是否允许网站查看和编辑该文件夹中的文件。脚本会把录像直接写进你选的文件夹。

> ⚠️ **不要直接选择系统文件夹**，例如「下载」「文档」「桌面」、整个磁盘（如 C 盘、D 盘的最外层），以及 Windows、Program Files 等系统目录。
> 浏览器出于安全考虑会拒绝或警告：「无法打开此文件夹，因为其中包含系统文件」。
>
> ✅ **解决方法**：在选择窗口中先进入「下载」等文件夹，点击 **「新建文件夹」**，例如命名为 `课程录像` 或课程名，**选中这个新建的子文件夹**再点「选择文件夹」。

之后浏览器会询问「允许 course.pku.edu.cn 编辑文件吗？」，请点击 **「编辑文件」/「允许」**。

建议每门课建一个子文件夹，例如 `下载/课程录像/操作系统/`，方便整理。

## 第七步：下载录像

### 单条下载

1. 在要下载的那一行，点击 **「下载」**。
2. 选择保存的子文件夹（见第六步）。
3. 脚本会在**后台标签页**中短暂打开这节课的播放页，自动获取视频地址后关闭该页。进度区显示「打开播放页，自动捕获播放列表」。
4. 之后开始下载，面板顶部的进度区会显示：
   - 进度条和 `分片 32 / 150（21%）`；
   - 已下载大小、视频时长、下载速度和预计剩余时间；
   - 面板折叠时，右下角小条也会显示 `下载 21%`。
5. 完成后状态栏显示 `已完成：L03-2026-09-30-第3-4节.mp4（…）`，文件已经保存在你选的文件夹里。

### 批量下载

1. 勾选要下载的录像，或点 **「全选」**。
2. 点击 **「下载选中」**，选择一次保存文件夹（见第六步）。
3. 脚本会自动逐条下载，默认同时下载 3 条，每条保存为独立的文件。
4. 进度区显示总体进度：已处理、成功、失败、取消、排队数量和已写入大小。列表中每一行显示该条的状态和进度。
5. 全部结束后，进度区显示 `批量下载已结束：成功 N · 失败 N · 取消 N`，每一行保留各自的结果。核对无误后点击 **「确定」**，面板恢复到下载前的样子。
6. 有失败的条目时，可以重新勾选它们，再点一次「下载选中」重试。

### 取消下载

- **单条下载**：点击进度区的 **「取消」**，或再次点击该行显示百分比的按钮。
- **批量下载**：点击某行的 **「取消此条」** 只取消这一条；点击进度区的 **「取消整个批次」** 停止全部未完成的条目。
- 取消后，未下载完的文件会被自动删除，不会留下损坏的文件；已经下载完成的文件会保留。

> 下载过程中请**不要关闭或刷新课堂实录页面**，否则下载会中断。关闭页面时浏览器会弹窗提醒。下载期间可以切换到其它标签页继续做别的事。

### 同名文件

如果文件夹里已经有同名文件，脚本**不会覆盖**，而是自动保存为 `文件名 (2).mp4`。

## 第八步：观看

下载得到的 `.mp4` 可以直接用 Windows「媒体播放器」或「电影和电视」、macOS 的 QuickTime、VLC、PotPlayer 等播放，也可以拖动进度条。

## 其它实用功能

| 按钮 | 作用 |
| --- | --- |
| **复制清单** | 复制所有录像（勾选了就只复制勾选的）的文件名、时间和教师，可以粘贴到 Excel 或笔记里 |
| **导出 JSON** | 导出整门课的录像清单文件，不包含任何链接或登录信息 |
| **打开选中** | 在后台标签页中打开勾选录像的播放页 |
| **复制名** | 复制该行的文件名 |
| **重新扫描** | 重新读取课堂实录的全部分页，例如老师新上传了录像时使用 |

### 自定义文件名

在「命名模板」中可以使用以下变量：

| 变量 | 含义 | 示例 |
| --- | --- | --- |
| `{index:02d}` | 序号（补零到 2 位）；`{index}` 表示不补零 | `03` |
| `{date}` | 上课日期 | `2026-09-30` |
| `{periodStart}` / `{periodEnd}` | 起止节次 | `3` / `4` |
| `{teacher}` | 教师 | `陈向群` |
| `{course}` | 面板中的课程名 | `操作系统` |
| `{time}` | 开始时间 | `1010` |

例如，模板 `{course}-L{index:02d}-{date}.mp4` 会得到 `操作系统-L03-2026-09-30.mp4`。文件名中不允许的字符会自动替换成 `_`。

## 常见问题

**页面右下角没有出现 Course Fetch 小条**

- 确认已完成[第二步](#第二步允许-tampermonkey-运行脚本)，并且 Tampermonkey 管理面板中 Course Fetch 的开关是开启状态。
- 点击 Tampermonkey 图标，看当前页面是否显示 Course Fetch 正在运行。
- 课堂实录可能显示在页面内嵌的框架里：在录像列表上点右键 →「在新标签页中打开框架」，在新标签页中使用。

**选择文件夹时提示「包含系统文件」或无法选择**

不能直接选「下载」「文档」「桌面」或整个磁盘等系统文件夹。请在其中**新建一个子文件夹**并选择它，详见[第六步](#第六步选择下载目录重要)。

**提示「当前浏览器不支持目录写入…改为在内存中合并」**

这表示你在使用 Firefox，或者课堂实录页面嵌在框架中。单条下载仍然可以完成，但整段视频会先放在内存里，完成后由浏览器下载，内存占用约等于视频大小（约 1 GB）。批量下载在这种情况下不可用。建议：

- 改用 Chrome 或 Edge；
- 或者右键「在新标签页中打开框架」，在独立页面中使用。

**弹窗提示「自动捕获播放列表超时」**

20 秒内没有获取到视频地址。常见原因：登录已过期，或者播放器需要手动点击播放。先在教学网中手动打开这节课，确认能正常播放后再试。

如果仍然不行，可以按 `F12` 打开开发者工具，切到「网络（Network）」标签，搜索 `m3u8`，复制出现的请求地址并粘贴到弹窗中。批量下载不会弹窗，会直接把该条标记为失败，可以改用单条下载。

**提示「无权限访问（HTTP 401/403）」**

登录已过期，或者你的账号没有这节录像的权限。重新登录教学网，确认能正常播放后再试。

**提示「…无法无损转为 MP4，已改存为 TS」**

个别录像的编码格式（例如 H.265）不能原样放进 MP4。为了不损失画质，脚本不会重新编码，而是自动改存为原始的 `.ts` 文件。`.ts` 可以用 VLC、PotPlayer 等播放器播放。

**提示「第 N 个分片解密失败」或「不是有效的 TS 数据」**

视频密钥可能已过期。刷新课堂实录页面后重新下载。

**提示「不支持的加密方式」**

这节录像使用了 DRM 版权保护，本工具不处理。

**列表中的录像数量比实际少**

请从课堂实录的**第 1 页**进入，然后点「重新扫描」。脚本只会从当前页向后翻页收集。

**怎么更新脚本？**

不需要手动操作：发布新版本后，Tampermonkey 会定期检查并自动更新（默认每天一次）。想立即更新，可以点击 Tampermonkey 图标 →「检查用户脚本更新」，或者重新点击[安装最新版](https://github.com/MiniYuanBot/course-fetch/releases/latest/download/course-fetch.user.js)。更新时 Tampermonkey 可能会请求确认新增的权限，请允许。

> 0.2.x 及更早版本是手动粘贴安装的，不会自动更新。请先在管理面板中删除旧的 Course Fetch，再按第三步重新安装一次，之后就会自动更新了。

**以前下载的 `.ts` 文件能转成 MP4 吗？**

可以。如果电脑上装有 [Node.js](https://nodejs.org/)（20 或以上版本），下载本项目的源代码（Releases 页面中的 Source code），在项目目录下运行：

```bash
npm run ts2mp4 -- "L01-2026-09-07-第7-8节.ts"
```

会在同一位置生成同名 `.mp4`。这同样是无损转换，几秒内就能完成。
