# Course Fetch

Course Fetch 是一个浏览器脚本，用于一键整理、批量下载北大教学网「课堂实录」的录像。

**[一键安装最新版](https://github.com/MiniYuanBot/course-fetch/releases/latest/download/course-fetch.user.js)**（需先完成下面的第一、二步）· [所有版本与更新说明](https://github.com/MiniYuanBot/course-fetch/releases)

打开课程的课堂实录页面后，Course Fetch 会自动列出整门课的全部录像，按时间排序并统一命名，例如 `L01-2026-09-07-第7-8节.mp4`。勾选录像后，点击下载即可保存为能直接播放的 MP4 文件。

## 为什么用 Course Fetch

- **收集整门课的录像**：自动翻页收集所有录像，去掉重复项，再按上课时间从 L01 开始编号。
- **统一文件名**：默认 `L序号-日期-第x-x节.mp4`，也可以自定义命名模板，下载后无需手动改名。
- **跳过放假的空录像**：放假时学校有时会照常上传一节空录像，它会占掉一个编号。按日期排除后，后面的课自动重新编号。
- **批量下载**：勾选多条录像后，只需选一次保存位置，默认同时下载 3 条。单条失败不影响其它录像，也可以取消单条或整个批次。
- **保存为 MP4**：边下载边转换成 MP4，不重新编码，画质和音质与原视频完全一致。文件比原始格式小约 5–10%，系统自带的播放器就能打开。
- **直接写入硬盘**：几 GB 的录像也能边下边存，不占内存，电脑不会因下载变卡。
- **查看下载进度**：显示百分比、已下载大小、速度和预计剩余时间。批量下载结束后列出每条结果，确认后恢复页面。
- **按账号权限下载**：只下载当前登录账号本来就能观看的录像，不破解、不绕过任何权限，也不会保存账号信息或视频密钥。
- **安装与更新**：点击链接即可安装。发布新版本后，Tampermonkey 会自动更新，无需安装其它软件。

> 课堂录像的版权归授课教师和学校所有。请仅用于个人学习，并遵守学校的相关规定，不要传播。

## 准备工作

| 项目 | 要求 |
| --- | --- |
| 浏览器 | 电脑版 **Chrome**、**Edge**、**Safari**、**Firefox** 均已支持。Chrome / Edge 可直接写入所选文件夹；Safari / Firefox 会用「浏览器保存」：优先写浏览器临时文件（可并行下载），否则在内存中合并（见[常见问题](#常见问题)） |
| 扩展 | Tampermonkey（油猴），下面会一步步安装 |
| 脚本 | 从 [Releases 页面](https://github.com/MiniYuanBot/course-fetch/releases/latest) 安装，见第三步 |
| 账号 | 能正常登录北大教学网，并且能在网页上播放要下载的录像 |
| 硬盘空间 | 每节课（约 2 小时）的录像约 0.6–1 GB |

## 第一步：安装 Tampermonkey

Chrome、Edge 用户可以在扩展商店免费安装 Tampermonkey。Safari 版通过 Mac App Store 官方分发，需要**付费购买**（一次性买断）。

**Chrome / Edge：**

1. 用 Chrome 或 Edge 打开 Tampermonkey 官网：<https://www.tampermonkey.net/>。
2. 点击对应浏览器的下载按钮，进入扩展商店：
   - Chrome：Chrome 网上应用店
   - Edge：Microsoft Edge 加载项
3. 点击「添加至 Chrome」或「获取」，在弹出的确认框中点「添加扩展程序」。
4. 安装完成后，点击浏览器右上角的拼图图标，找到 Tampermonkey，再点旁边的图钉，将它固定到工具栏，方便之后使用。

**Safari（macOS）：**

1. 打开 Mac 上的 **App Store**，搜索 **Tampermonkey**，购买并安装。
2. 打开 Safari 的「设置 → 扩展」，找到 Tampermonkey，勾选启用。
3. 首次使用时，Safari 可能询问是否允许 Tampermonkey 在网站上运行，请选择允许。

## 第二步：允许 Tampermonkey 运行脚本

新版 Chrome 和 Edge 需要手动开启用户脚本权限，**跳过这一步，脚本不会生效**。Safari 用户可直接跳到第三步。

**Chrome：**

1. 在地址栏输入 `chrome://extensions` 并回车。
2. 找到 Tampermonkey，点击「详细信息」。
3. 打开 **「允许用户脚本」（Allow User Scripts）** 开关。
   - 如果找不到这个开关，说明 Chrome 版本较旧，改为打开页面右上角的 **「开发者模式」** 开关。

**Edge：**

1. 在地址栏输入 `edge://extensions` 并回车。
2. 打开左侧（或页面上方）的 **「开发人员模式」** 开关。
3. 找到 Tampermonkey，点击「详细信息」，如果有 **「允许用户脚本」** 开关，也一并打开。

## 第三步：安装 Course Fetch 脚本

**Chrome / Edge / Firefox：**

1. 打开最新版本的 [Releases 页面](https://github.com/MiniYuanBot/course-fetch/releases/latest)。
2. 在页面下方的 **Assets** 中点击 **`course-fetch.user.js`**，也可以直接点击[安装最新版](https://github.com/MiniYuanBot/course-fetch/releases/latest/download/course-fetch.user.js)。
3. Tampermonkey 会自动打开安装页面，显示脚本名称 **Course Fetch** 和版本号，点击 **「安装」**。
4. 点击 Tampermonkey 图标 →「管理面板」，确认列表中有 **Course Fetch**，且右侧开关已**开启**。

**Safari：**

Safari 版的 Tampermonkey 无法像 Chrome 那样拦截 `.user.js` 链接，点击上面的链接只会把文件下载下来，请改用「从 URL 安装」：

1. 点击 Tampermonkey 图标 →「管理面板」，在左侧选择 **「实用工具」**。
2. 找到 **「从 URL 安装」**，粘贴下面这个地址：
   `https://github.com/MiniYuanBot/course-fetch/releases/latest/download/course-fetch.user.js`
3. 点击「安装」，在随后弹出的页面上再点一次 **「安装」**。
4. 回到管理面板，确认 **Course Fetch** 右侧的开关键已**开启**。

之后新版本仍会自动更新，不需要重复这一步。

> ⚠️ Safari 上**不要**用「把 `.user.js` 文件拖进 Tampermonkey 面板」的方式安装：拖入的文件里中文会变成乱码。请用上面的「从 URL 安装」，或在面板中新建脚本后粘贴内容。

> **Chrome / Edge 没有弹出安装页面、而是直接下载了文件？** 说明前两步尚未完成，或 Tampermonkey 没有启用。检查后重新点击安装链接。
> 也可以在 Tampermonkey 管理面板的「实用工具 → 从 URL 安装」中粘贴上面的安装链接。

## 第四步：打开课堂实录，确认脚本已运行

1. 登录 [北大教学网](https://course.pku.edu.cn)，进入一门有录像的课程，点击左侧菜单中的 **「课堂实录」**。
   - 建议从课堂实录的**第 1 页**进入，这样脚本能收集到全部分页。
2. 稍等片刻，页面**右下角**会出现 `Course Fetch · 32 条` 小条，数字表示录像条数。脚本会自动扫描所有分页，扫描时显示「扫描中…」。
3. 点击这个小条，展开 Course Fetch 面板。

第一次下载时，Tampermonkey 可能会弹窗询问是否允许脚本访问 `pku.edu.cn` 下的某个域名（例如 `resourcese.pku.edu.cn`），请选择 **「总是允许」**。

## 第五步：检查录像列表

面板中各项的含义：

| 区域 | 说明 |
| --- | --- |
| **课程** | 自动识别的课程名。识别得不准可以直接修改，修改后会被记住 |
| **命名模板** | 文件名规则，默认 `L{index:02d}-{date}-第{periodStart}-{periodEnd}节.mp4`，修改后列表中的文件名会实时更新；点「重置」恢复默认 |
| **输出格式** | 默认 **MP4（推荐）**；也可以选 **TS（原始流）**。选择会被记住 |
| **排除日期** | 折叠区域，平时收起。每行一组日期，「排除」只影响当前课程，「存为标签」则对所有课程生效（见下方「排除放假等空回放」） |
| **录像列表** | 按上课时间排序，L01 是最早的一节课。每行有「打开」「复制名」「排除」「下载」四个按钮 |
| **提示** | 如果有解析失败、翻页失败、重复录像等情况，会在这里列出 |

### 排除放假等空回放

放假时学校有时会照常上传一节内容为空的录像，它会占掉一个编号，让后面所有课的文件名整体往后挪一位（第 5 次课变成 `L06`）。

被排除的录像会变灰、序号显示 `—`，不参与编号，也不会被「全选」「下载选中」「复制清单」「导出 JSON」带上；单独点它的「下载」仍然可用，可以用来确认是不是真的空。

展开面板里的 **「排除日期」**（默认收起），在里面填日期。第一行左端是 **＋**，点一下多一行；其余行左端是 **－**，可以把整行删掉。每行各管一组日期，互不影响，右端有三个按钮：

| 按钮 | 作用 |
| --- | --- |
| **排除** | 排除当前课程中落在**这一行**日期的录像，按课程记住 |
| **恢复** | 恢复这一行日期对应的条目（由标签排除的要停用或删除标签） |
| **存为标签** | 在这一行下面填个名字（如「中秋节」）再点「保存」，**所有课程**都会自动排除这些日期 |

日期写法：

| 写法 | 含义 |
| --- | --- |
| `2026-10-01` | 单个日期 |
| `2026-10-01~2026-10-07` | 日期段（`~` 也可写成 `～`、`至`、`到`） |
| `2026-10-01 2026-11-02~2026-11-06` | 一行里写多段，用空格或逗号分隔 |

保存好的标签会列在日期行下方，前面的勾选框可以临时**停用**（不删除，只是暂时不生效），点 **「删除」** 彻底移除。被标签排除的行在列表里标注标签名（如「中秋节」），要恢复就停用或删除对应标签。

## 第六步：选择下载目录（重要）

无论是单条还是批量下载，首次点击下载时，浏览器都会弹出**「选择文件夹」**窗口，询问是否允许网站查看和编辑其中的文件。脚本会将录像直接写入所选文件夹。

> ⚠️ **不要直接选择系统文件夹**，例如「下载」「文档」「桌面」、整个磁盘（如 C 盘、D 盘的最外层），以及 Windows、Program Files 等系统目录。
> 浏览器出于安全考虑会拒绝或警告：「无法打开此文件夹，因为其中包含系统文件」。
>
> ✅ **解决方法**：在选择窗口中进入「下载」等文件夹，点击 **「新建文件夹」**，例如命名为 `课程录像` 或课程名，再**选中新建的子文件夹**，点击「选择文件夹」。

之后浏览器会询问「允许 course.pku.edu.cn 编辑文件吗？」，请点击 **「编辑文件」/「允许」**。

建议每门课建一个子文件夹，例如 `下载/课程录像/操作系统/`，方便整理。

## 第七步：下载录像

### 单条下载

1. 找到要下载的录像，点击该行的 **「下载」**。
2. 选择用于保存录像的子文件夹（见第六步）。
3. 脚本会短暂地在**后台标签页**中打开这节课的播放页，自动获取视频地址，然后关闭该页。进度区会显示「打开播放页，自动捕获播放列表」。
4. 下载开始后，面板顶部的进度区会显示：
   - 进度条和 `分片 32 / 150（21%）`；
   - 已下载大小、视频时长、下载速度和预计剩余时间；
   - 面板折叠时，右下角小条也会显示 `下载 21%`。
5. 下载完成后，状态栏显示 `已完成：L03-2026-09-30-第3-4节.mp4（…）`，文件已保存到所选文件夹。

### 批量下载

1. 勾选要下载的录像，或点 **「全选」**。
2. 点击 **「下载选中」**，选择一次保存文件夹（见第六步）。
3. 脚本会自动下载所选录像，默认同时下载 3 条，每条保存为独立文件。
4. 进度区显示总体进度，包括已处理、成功、失败、取消、排队数量和已写入大小。列表各行显示对应录像的状态和进度。
5. 全部结束后，进度区显示 `批量下载已结束：成功 N · 失败 N · 取消 N`，各行保留下载结果。核对无误后点击 **「确定」**，面板恢复到下载前的状态。
6. 下载失败的录像可以重新勾选，再点「下载选中」重试。

### 取消下载

- **单条下载**：点击进度区的 **「取消」**，或再次点击该行显示百分比的按钮。
- **批量下载**：点击某行的 **「取消此条」** 只取消这一条；点击进度区的 **「取消整个批次」** 停止全部未完成的条目。
- 取消后，脚本会自动删除未下载完的文件，不会留下损坏文件；已经下载完成的文件会保留。

> 下载过程中请**不要关闭或刷新课堂实录页面**，否则下载会中断。关闭页面时，浏览器会弹窗提醒。下载期间可以切换到其它标签页做别的事。

### 同名文件

如果文件夹中已有同名文件，脚本会自动保存为 `文件名 (2).mp4`，**不会覆盖原文件**。

## 第八步：观看

下载后的 `.mp4` 可以直接用 Windows「媒体播放器」或「电影和电视」、macOS 的 QuickTime、VLC、PotPlayer 等播放，并支持拖动进度条。

## 其它实用功能

| 按钮 | 作用 |
| --- | --- |
| **复制清单** | 复制所有录像（勾选了就只复制勾选的）的文件名、时间和教师，可以粘贴到 Excel 或笔记里 |
| **导出 JSON** | 导出整门课的录像清单文件，不包含任何链接或登录信息 |
| **打开选中** | 在后台标签页中打开勾选录像的播放页 |
| **复制名** | 复制该行的文件名 |
| **重新扫描** | 重新读取课堂实录的全部分页，例如老师新上传了录像时使用 |

### 自定义文件名

在「命名模板」中可以使用以下变量：

| 变量 | 含义 | 示例 |
| --- | --- | --- |
| `{index:02d}` | 序号（补零到 2 位）；`{index}` 表示不补零 | `03` |
| `{date}` | 上课日期 | `2026-09-30` |
| `{YYYY}` / `{YY}` / `{MM}` / `{DD}` | 日期的年 / 年后两位 / 月 / 日 | `2026` / `26` / `09` / `30` |
| `{periodStart}` / `{periodEnd}` | 起止节次 | `3` / `4` |
| `{teacher}` | 教师 | `陈向群` |
| `{course}` | 面板中的完整课程名 | `计算概论（B）上机(24-25学年第1学期)` |
| `{courseName}` | 去掉末尾学年学期后的课程名 | `计算概论（B）上机` |
| `{academicYear}` | 学年，保留年份位数 | `24-25` |
| `{semester}` | 学期编号；可用 `{semester:02d}` 补零 | `1` |
| `{time}` | 开始时间 | `1010` |

例如，模板 `{course}-L{index:02d}-{date}.mp4` 会得到 `操作系统-L03-2026-09-30.mp4`。如果想用短日期，可以把 `{date}` 换成 `{YY}{MM}{DD}`，得到 `L03-260930.mp4`。文件名中不允许的字符会自动替换成 `_`。

对于 `计算概论（B）上机(24-25学年第1学期)`，模板 `{courseName}-{academicYear}-S{semester}-L{index:02d}.mp4` 会得到 `计算概论（B）上机-24-25-S1-L03.mp4`。只拆分末尾的学年学期括号，支持中英文括号、两位或四位年份（如 `2024-2025`），课程名里的 `（B）` 等括号会保留。没有匹配到后缀时，`{courseName}` 使用完整课程名，`{academicYear}` 和 `{semester}` 为空。

## 常见问题

**页面右下角没有出现 Course Fetch 小条？**

- 确认已完成[第二步](#第二步允许-tampermonkey-运行脚本)，且 Tampermonkey 管理面板中 Course Fetch 的开关已开启。
- 点击 Tampermonkey 图标，查看当前页面是否显示 Course Fetch 正在运行。
- 课堂实录可能嵌在框架中。可在录像列表上点右键 →「在新标签页中打开框架」，然后在新标签页中使用。

**选择文件夹时提示「包含系统文件」或无法选择？**

不能直接选「下载」「文档」「桌面」或整个磁盘等系统文件夹。请在其中**新建一个子文件夹**并选择它，详见[第六步](#第六步选择下载目录重要)。

**提示「当前浏览器不支持目录写入」？**

这表示你在使用 Safari 或 Firefox，或课堂实录页面嵌在框架中。脚本会自动改用「浏览器保存」模式，单条和批量下载都能使用：

- 优先写入浏览器临时文件（OPFS），批量下载时可并行处理，完成后交给浏览器下载，不额外占用内存；
- 临时文件不可用时，先在内存中合并整段视频，再交给浏览器下载。批量下载会逐条处理，每条占用的内存约等于视频大小（约 1 GB）。

如果页面嵌在框架中，建议右键选择「在新标签页中打开框架」，即可恢复直接写入所选文件夹；也可以改用 Chrome 或 Edge。

**弹窗提示「自动捕获播放列表超时」？**

脚本在 20 秒内未获取到视频地址，常见原因是登录已过期，或播放器需要手动点击播放。先在教学网中手动打开这节课，确认能正常播放后再试。

如果仍然失败，可以按 `F12` 打开开发者工具，切到「网络（Network）」标签，搜索 `m3u8`，复制出现的请求地址并粘贴到弹窗中。批量下载不会弹窗，会直接将该条标记为失败，此时可以改用单条下载。

**提示「无权限访问（HTTP 401/403）」？**

登录已过期，或者你的账号没有这节录像的权限。重新登录教学网，确认能正常播放后再试。

**提示「…无法无损转为 MP4，已改存为 TS」？**

个别录像的编码格式（例如 H.265）不能原样封装为 MP4。为避免损失画质，脚本会自动改存为原始的 `.ts` 文件，不重新编码。`.ts` 可以用 VLC、PotPlayer 等播放器播放。

**提示「第 N 个分片解密失败」或「不是有效的 TS 数据」？**

视频密钥可能已过期。刷新课堂实录页面后重新下载。

**提示「不支持的加密方式」？**

这节录像使用了 DRM 版权保护，本工具不处理。

**列表中的录像数量比实际少？**

请从课堂实录的**第 1 页**进入，然后点「重新扫描」。脚本只会从当前页向后翻页收集。

**放假那几天的编号错位了？**

放假时空录像会占掉一个编号，让后面的课整体往后挪一位。展开「排除日期」，填上那几天的日期，点「存为标签」并起个名（如「中秋节」），所有课程都会自动排除这些日期的录像并重新编号；只想影响当前课程时点「排除」，或用列表行尾的「排除」。详见[排除放假等空回放](#排除放假等空回放)。

**怎么更新脚本？**

发布新版本后，Tampermonkey 会定期检查并自动更新（默认每天一次），无需手动操作。想立即更新，可以点击 Tampermonkey 图标 →「检查用户脚本更新」，或重新点击[安装最新版](https://github.com/MiniYuanBot/course-fetch/releases/latest/download/course-fetch.user.js)。更新时，Tampermonkey 可能会请求确认新增的权限，请允许。

**下载的 `.ts` 文件能转成 MP4 吗？**

可以。如果电脑上装有 [Node.js](https://nodejs.org/)（20 或以上版本），下载本项目的源代码（Releases 页面中的 Source code），在项目目录下运行：

```bash
npm run ts2mp4 -- "L01-2026-09-07-第7-8节.ts"
```

命令会在同一位置生成同名 `.mp4`，同样是无损转换，几秒内即可完成。
